## 📊 API ENDPOINTS USED:

Your HTML app will call these webhook worker endpoints:

### Get All Active Orders:
```
GET https://cartwheel-webhook.jamiececil.workers.dev/orders
```
Returns all active orders for all drivers

### Get Settings:
```
GET https://cartwheel-webhook.jamiececil.workers.dev/settings
```
Returns current configuration

### Update Settings:
```
POST https://cartwheel-webhook.jamiececil.workers.dev/settings
Body: { timers: {...}, notifications: {...}, templates: {...} }
```
Updates configuration

### Get Driver Orders:
```
GET https://cartwheel-webhook.jamiececil.workers.dev/driver/+1234567890
```
Returns orders for specific driver

## 🎯 COLOR CODING LOGIC:

```javascript
function getDriverColor(orders) {
  if (!orders || orders.length === 0) {
    return 'gray'; // No orders
  }
  
  // Check for conflicts
  if (hasConflict(orders)) {
    return 'red'; // CONFLICT!
  }
  
  // Get most recent order
  const latestOrder = orders[orders.length - 1];
  
  switch(latestOrder.status) {
    case 'assigned':
      return 'blue';
    case 'transit_to_pickup':
      return 'yellow';
    case 'at_pickup':
    case 'ready_for_pickup':
      return 'orange';
    case 'picked_up':
    case 'transit_to_dropoff':
      return 'green';
    case 'at_dropoff':
      return 'purple';
    default:
      return 'gray';
  }
}
```

## 🐛 TROUBLESHOOTING:

**Orders not showing?**
- Check webhook worker URL is correct in settings
- Verify worker has KV and Queue bindings
- Check Cloudflare logs for webhook activity

**Colors not updating?**
- Refresh the page
- Check internet connection
- Verify orders are in KV storage

**SMS not sending?**
- Check Twilio credentials in worker
- View Cloudflare logs for errors
- Test with manual curl command

**Conflicts not detected?**
- Check "Minimum Buffer" setting
- Verify order times are correct
- Look at Cloudflare logs for conflict detection
