## ⚡ 5-Minute Setup

### 1. Open the File (1 min)
- Double-click to open in browser
- Enter your name: "Jamie"
- Select role: "Dispatcher"

### 2. Configure (2 min)
- Click "Setup"
- Enter your 5 Twilio credentials:
  - Account SID (AC...)
  - API Key SID (SK...)
  - API Key Secret (you saved this)
  - Service SID (IS...)
  - Phone Number (+1...)
- Click "Save"

### 3. Upload Drivers (1 min)
- Click "📁 Upload Excel"
- Select your driver list
- ✅ All loaded!

### 4. Test It (1 min)
**Send yourself a test:**
- Click "👥 Drivers" tab
- Click your name (if in list)
- OR click "📤 Bulk Message"
- Select yourself
- Send test message
- ✅ Receive it with signature!

## 🎯 Daily Use

### Message One Driver:
```
1. Click "👥 Drivers" tab
2. Search or scroll to driver
3. Click their name
4. Type message
5. Send (signature auto-added)
```

### Bulk Message Team:
```
1. Click "📤 Bulk Message"
2. Filter by team (optional)
3. Select drivers
4. Type: "Hi {firstName}, your route is ready!"
5. Send to all at once
```

### See All Conversations:
```
1. Click "💬 Conversations" tab
2. See every active conversation
3. Click any to view/reply
4. Team members see same list
```
